Payload Components helps Payload v3 and Next.js 15/16 teams deliver reusable
page blocks without rebuilding the same integration layer. Blocks install as
reviewable source, while the CLI connects Pages, RenderBlocks, generated types,
and the admin import map.

Source: https://github.com/Ducksss/payload-components
