Orbi is an open-source coding agent that implements GitHub Issues labeled `ai-ready`. It runs tests, opens a PR and uses a separate AI session to review and fix the change before merge. Maintainers request releases through `ai-release` issues; Orbi runs the release checks and publishes the tag and GitHub Release. It also handles deployment and investigation tickets. Self-host the AGPL-3.0 engine with your own model configuration, or use Orbi Cloud.
