CurlShot is a screenshot API for developers. One HTTP request turns a URL, HTML or Markdown into a PNG, JPEG, WebP, PDF or a scrolling video (MP4, WebM, GIF). Pages render in a real browser.

## Features

- Full-page capture, with lazy images loaded on the way down
- Phone, tablet and desktop device presets
- Cookie banners, ads and chat bubbles removed before the capture
- Capture one element by CSS selector, dark mode, custom CSS and JavaScript
- Async jobs with signed webhooks and bulk runs of up to 100 URLs
- MCP server (`https://curlshot.com/api/mcp`) so AI agents can take screenshots, plus OpenAPI 3.1 and llms.txt
- Works from any language with no SDK (cURL, Node.js, Python, PHP, Go, Ruby examples); n8n community node

## Free tier

100 screenshots a month, no credit card. A free online tool on the home page works without an account. Docs: https://curlshot.com/docs
