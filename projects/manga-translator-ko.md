만화 번역기 AI는 Ficory LLC가 운영하는 기업급 만화 리더·번역 플랫폼으로, 지원하는 모든 번역 언어인 100개 이상의 언어로 개인 사용자의 여러 만화 페이지를 일괄 번역하고 작품에 맞는 맞춤 번역을 지원합니다. 스튜디오 사용자는 완전한 온라인 Photoshop 방식 편집기로 번역문과 페이지 레이아웃을 수정하며, 개발자는 API를 개인 작업 흐름에 연결하여 이미지 업로드, 번역 작업 제출, 진행 상태 확인과 결과 다운로드를 자동화할 수 있습니다.

## 개발자 작업 흐름

개발자는 API Key로 인증한 뒤 이미지 배치를 제출하고 반환된 작업 식별자로 처리 상태를 조회합니다. API는 번역 이미지 URL을 반환하며, 공식 예제는 Python, cURL과 Node.js 요청을 설명합니다. 자동 번역 결과는 인명, 용어 및 말풍선 배치를 검토한 후 사용해야 합니다.

## 이용 조건

이 서비스는 제한된 무료 이용량과 유료 크레딧·구독을 함께 제공합니다. 무료 크레딧의 현재 지급 조건과 사용 한도는 공식 요금 및 계정 화면에서 확인해야 합니다. 무제한 무료 서비스나 오픈소스 제품으로 소개하지 않습니다.
