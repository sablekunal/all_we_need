YYLO Skills is the canonical, independently versioned source for the eight reusable agent skills used across the YYLO family: Kanban and task planning, project discovery and understanding, wiki and artifact records, workflow validation, and the Ralph execution loop (every canonical slug ends in -yylo). Skills install into Claude Code, Codex and Pi with the open skills CLI (`npx skills add yylo-dev/yylo-skills`), and the repository runs alongside the YYLO CLI, YYLO Ledger and YYLO Benchmark packages already listed here.
